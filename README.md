# WVP-SSV-Web

`wvp-ssv-web` 是 SSV 浏览器前端的独立设计与开发仓库，面向事件证据查看和后续多路实时视频预览。当前仓库包含初始规格、实施计划和旧页面源码参考快照，尚无可运行的前端应用。

- [实施计划](docs/plans/2026-10-12-wvp-ssv-web-plan.md)
- [旧 Web 源码参考说明](reference/wvp-ssv/README.md)

`reference/wvp-ssv/` 中的源码仅用于理解旧原型的页面行为和接口线索，不属于当前实现，也不保证可运行。后端事件 API 与视频播放会话接口需在集成阶段确认。
